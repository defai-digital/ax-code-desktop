# Updates

You can check your current version at **Settings → About AX Code**.

## Desktop app

Choose **AX Code → Check for Updates** from the **AX Code** application menu (on macOS, Windows, and Linux). The app checks for the newest stable `v*` release and waits for you to confirm before downloading and installing.

You can also run the install command for your platform again (see [Install](/install/)), or download a specific release from [GitHub Releases](https://github.com/defai-digital/ax-code-desktop/releases). Quit **AX Code** first; the installer replaces the app while keeping your user data and credentials.

## The bundled AX Code runtime

The signed desktop app runs its own bundled copy of AX Code, pinned to the app version. It updates automatically when AX Code Desktop updates. If you point AX Code Desktop at another `ax-code` binary instead, see [AX Code Server](/ax-code-server/) for how that server is managed.

## Standalone `ax-code` CLI

If you also installed the `ax-code` CLI for terminal use, it has its own version and update channel — updating AX Code Desktop does not touch it, and vice versa.
