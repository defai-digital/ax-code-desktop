# Magic Prompts

AX Code Desktop uses built-in prompts behind the scenes whenever it runs an automated flow — writing a commit message, drafting a PR, reviewing an issue, resolving a conflict, or summarizing a session.

The **Settings → Magic Prompts** editor has been retired. Existing prompt overrides continue to work at runtime, while new customization is handled through [Commands](/commands-snippets/) and [Skills](/skills/).
