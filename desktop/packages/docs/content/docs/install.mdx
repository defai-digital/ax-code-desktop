# Install

AX Code Desktop is the graphical app for local AX Code sessions. The signed app includes a pinned
AX Code runtime, so a normal installation needs neither a separate CLI on `PATH` nor a Node.js installation.
Use the supported installation commands from the [Desktop README](https://github.com/defai-digital/ax-code-desktop#install).

Close **AX Code** before installing. The installer verifies the signed release and keeps existing user
data and credentials. On macOS and Ubuntu it may ask for an administrator password.

## macOS (Apple Silicon)

macOS 13 or newer on Apple Silicon:

```bash
curl -fsSL https://download.automatosx.com/ax-code-desktop/install | bash
```

Open **AX Code** from `/Applications/AX Code.app` after installation. Homebrew is not required.

## Windows

Windows x64 (AMD64), PowerShell 5.1 or newer:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://download.automatosx.com/ax-code-desktop/install.ps1 | iex"
```

The bootstrap checks the Authenticode signature before opening the installer. Confirm that the publisher
is **DEFAI Private Limited**. Open **AX Code** from the Start menu under **DeFAI Digital** or from the desktop shortcut.

## Ubuntu Desktop 24.04+

Ubuntu Desktop 24.04 or newer on amd64 or arm64:

```bash
curl -fsSL https://download.automatosx.com/ax-code-desktop/install | bash
```

Launch **AX Code** from the app menu, or run `ax-code-desktop`.

## After installation

1. Open **AX Code**.
2. Add a project folder.
3. Configure a model provider in the app.
4. Start or select a session, then review the diff, Git state, files and terminal.

Desktop updates its bundled runtime when the app updates. It does not install the standalone `ax-code`
command on `PATH`. A separately installed CLI has its own version and installation channel; see [Updates](/updates/).

## CLI and terminal UI only

If you prefer terminal, SSH or headless workflows on a supported host, install the standalone CLI using
its [README installation method](https://ax-code.app/en/docs/getting-started/install-runtime/).
This installation is optional for Desktop users. Its installers include the required Node.js runtime.

macOS Apple Silicon and Ubuntu 24.04+ (amd64 or arm64):

```bash
curl -fsSL https://download.automatosx.com/ax-code/install | bash
```

Windows x64:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://download.automatosx.com/ax-code/install.ps1 | iex"
```

After installation, run `ax-code` in a project folder, then connect a provider with `/connect`.
Installing or updating Desktop does not install or update this separate CLI, or vice versa.

## Manual packages and verification

Manual Desktop packages belong to the
[AX Code Desktop releases](https://github.com/defai-digital/ax-code-desktop/releases),
not the runtime repository. Each installer has a detached `.minisig` signature.
The supported commands above verify the signature, size and hash before installing.
A direct download does not perform those bootstrap checks automatically; follow the
[manual verification instructions](https://github.com/defai-digital/ax-code-desktop/blob/main/desktop/docs/MINISIGN.md).

| Platform            | Installer                           | Portable package                          |
| ------------------- | ----------------------------------- | ----------------------------------------- |
| macOS Apple Silicon | `AX-Code-<version>-mac-arm64.dmg`    | `AX-Code-<version>-mac-arm64.zip`          |
| Windows x64         | `AX-Code-<version>-win-x64.exe`      | `AX-Code-<version>-win-x64.zip`            |
| Ubuntu amd64        | `AX-Code-<version>-linux-amd64.deb`  | `AX-Code-<version>-linux-x86_64.AppImage`   |
| Ubuntu arm64        | `AX-Code-<version>-linux-arm64.deb`  | `AX-Code-<version>-linux-arm64.AppImage`   |

## Supported platforms

Current Desktop installers support macOS 13+ Apple Silicon, Windows x64, and Ubuntu Desktop 24.04+
(amd64 and arm64). There is no current installer for Intel Macs or Windows ARM64. Alpine and other
musl-based distributions are outside the supported set. The CLI also has no current Intel Mac or
Windows ARM64 installer, so it is not an automatic fallback for those architectures.

AX Engine local inference is available on eligible Apple Silicon Macs. On Windows and Ubuntu, use a
hosted provider or a supported OpenAI-compatible model endpoint. Desktop's UI, managed runtime and native
bridges listen on loopback; SSH instance switching, LAN binding and public tunnels are disabled.

## Development checkout

Contributor builds run from the AX Code Desktop repository:

```bash
pnpm install
pnpm run build
# macOS
node desktop/packages/electron/scripts/package.mjs --mac zip --publish=never
# Linux (on Ubuntu)
node desktop/packages/electron/scripts/package.mjs --linux --x64 --publish=never
```
