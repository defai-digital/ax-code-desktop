# Quickstart

## Fastest path

1. Install AX Code Desktop for macOS (Apple Silicon), Windows x64, or Ubuntu Desktop 24.04+ (see [Install](/install/)). The signed app bundles the pinned AX Code runtime, so no separate CLI or Node.js install is required.
2. Launch **AX Code** from Applications (macOS), the Start Menu or desktop shortcut (Windows), or the app menu (Ubuntu).
3. Add a project folder.
4. Connect a hosted or OpenAI-compatible provider — or on an eligible Apple Silicon Mac, connect AX Engine as a local provider.

You should see the AX Code Desktop workspace. Once a project is added, you can start a session, review diffs, and run Git or terminal commands in the same window.

AX Code Desktop is local-only. It listens on loopback addresses and does not support remote access.

If the app doesn't load, check [Troubleshooting](/troubleshooting/).

## Providers by platform

- **macOS Apple Silicon** — use hosted providers or AX Engine locally on eligible Macs
- **Windows x64 & Ubuntu 24.04+** — use hosted providers or an OpenAI-compatible endpoint
