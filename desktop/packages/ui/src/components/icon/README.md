# Icon System

AX Code Desktop renders icons from a single SVG sprite. The glyphs come from
[Phosphor Icons](https://phosphoricons.com) (MIT License, via `@phosphor-icons/core`). The sprite is injected
into the DOM once, and each icon references a symbol with `<use href="#ax-icon-name"/>`.

## Usage

```tsx
import { Icon } from "@/components/icon/Icon"

<Icon name="arrow-down-s" className="h-4 w-4" />
<Icon name="loader-4" className="size-4 animate-spin" />
```

## Icon names

Icon names are stable kebab-case identifiers such as `arrow-down-s`, `git-branch`, or `terminal-box`. They are
not Phosphor names. `desktop/scripts/icon-sprite-map.mjs` maps each name to a Phosphor glyph and weight, so
a glyph can change without touching any call site.

Names ending in `-fill` render the Phosphor `fill` weight. Every other name uses the default weight in the
map unless its entry sets one.

## Adding or changing an icon

1. Pick a glyph at https://phosphoricons.com and add or edit its entry in `desktop/scripts/icon-sprite-map.mjs`.
   An entry is either a Phosphor name or `{ icon, weight, flip }`.
2. Run `pnpm --filter @openchamber/ui icons:sprite` to regenerate `sprite.ts`.
3. Use it: `<Icon name="new-icon-name" />`. `IconName` is type-checked against the sprite.

The generator fails when an `<Icon name="...">` literal in `packages/ui/src` has no map entry, or when a map
entry points at a Phosphor asset that does not exist.

## Sizing

The `Icon` component has no `size` prop. Use Tailwind classes:

```tsx
<Icon name="arrow-down-s" className="h-4 w-4" />   {/* 16px */}
<Icon name="arrow-down-s" className="size-5" />      {/* 20px */}
```

## Type safety

```tsx
import type { IconName } from "@/components/icon/icons"

const icon: IconName = "arrow-down-s" // type-checked
```

## Architecture

- `sprite.ts` is generated by `desktop/scripts/generate-icon-sprite.mjs`. Do not edit it by hand.
- `Icon.tsx` is the `<Icon>` component. It injects the sprite on first render.
- `icons.ts` exports the `IconName` type.

The sprite is a hidden `<svg id="ax-icon-sprite">` that holds one `<symbol id="ax-icon-{name}">` per icon, with
the Phosphor 256-unit view box. Each `<Icon>` renders `<svg class="ax-icon"><use href="#ax-icon-{name}"/></svg>`.
Glyph paths are filled with `currentColor`, so icons follow the text color.
