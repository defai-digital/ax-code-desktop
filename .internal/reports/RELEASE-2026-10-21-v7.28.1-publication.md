## Changes and verified bug fixes

The release integrates the committed supervision and WebMCP work through r24, preserving the independent Desktop/runtime boundary.

- Discard rejects symlink parents before index mutation, preserves directories replacing staged or committed files in either scope, and does not replace a failed Git cleanup with recursive filesystem deletion. Real disposable repositories reproduced the external-file and replacement-directory losses before repair.
- Repeated browser close confirmations remain bound to their original target views. Owner close waits for confirmation, actual owner loss adopts vetoing pages, and recoverable host crashes retain the original owner and guest. A real Electron probe verified crash/reload retention, cancelled and approved closure, and forced owner-loss adoption with injected confirmation answers.
- Stable guest/debugger handles allow cleanup after native destruction. Bracketed assignment paths and nested diagnostic values share the redaction parser; advisory diagnosis covers properties beyond the form presentation cap.
- Credential diagnostics retain sensitivity across numeric elements, quoted compound paths and sensitive ancestors. JSON input drafts are masked when structural redaction changes their preview. Executable input is not silently shortened.
- Plain prose and URL-scheme scanning avoid quadratic rescanning. A 66 KB prose probe improved from approximately 2086 ms to 1.2 ms on the same host; regression fixtures cover spaces, hyphens, dots and whitespace.
- Native WebMCP initialization has a total deadline and aborts on destruction, renderer loss, debugger detachment or close. Late responses cannot revive retired guests. Transport fault injection covers all three initialization stages, four lifecycle interrupts, queued creation and shutdown; this is not a claim of a live renderer-hang journey.
- Previously integrated fixes retain the primary startup directory, secondary window/grid ownership, saved split ratios, page/session/provider identity, cancellation, exact checker receipts, and checked Git content reads.
