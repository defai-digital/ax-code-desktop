**What the app does**
- Defaults to the bundled `sales.csv` sitting next to the app; uploading a CSV replaces it.
- Validates the schema (`month, region, revenue`, case/whitespace-tolerant headers) with actionable errors; coerces `revenue` to numbers and warns about rows it drops.
- Region dropdown (sorted, first region preselected), bar chart of monthly revenue for that region, plus total and month count.
- "Download filtered rows (CSV)" exports exactly the selected region's rows, named e.g. `sales_east.csv`.

**How to use**
In AX Code Desktop, click **Run** on the app declaration below; if dependencies are missing, choose **Prepare and run** as a separate step. Desktop owns the port and preview. Fallback in any terminal, from this project directory:

```
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

Then open the local URL Streamlit prints, pick or upload a CSV, select a region, and use the download button.

