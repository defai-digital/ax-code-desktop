# AX Code Desktop 7.26.0 publication evidence

Date: 2026-10-16 UTC
Status: Published and independently verified.

The explicit user request authorizes publication under ADR-012.
[Release 7.26.0](https://github.com/defai-digital/ax-code-desktop/releases/tag/v7.26.0)
and its lightweight tag pin `8ed7b95de594bbecf96fbd8304225c93dead90bc`. The candidate consumes exact published
SDK 2.6.22 and signed AX Code runtime 7.26.0.

## Review and reproduced fixes

Muse CLI and Grok CLI completed bounded source-snapshot reviews. Muse ran with
filesystem writes, shell and web tools disabled. Grok returned a successful terminal
result, exit code 0 and zero tool calls. Broader Grok attempts timed out without
assistant output; additional compatibility/fast-model attempts were cancelled after
the narrow review completed. None of those attempts count as successful reviews.
Review text and dispositions are recorded in
`.internal/reviews/release-7.26.0/` and signed release attachments.

Four reproduced corrections are included:

- Scheduled CLI checks and settings re-entry now apply server cache expiry instead
  of reading an old GET result indefinitely. Cached progress reads remain non-spawning.
- Settings resumes following a running upgrade after connectivity returns, preventing
  permanently disabled controls.
- A failed authoritative pre-check cannot start an installer without a confirmed
  available update.
- A stalled status request is aborted at the remaining reachability deadline,
  including recovery POST and response-body handling.

Regression cases failed before their fixes. The six-hour notification regression,
settings re-entry, cached polling, connection recovery, failed pre-check and stalled
request tests pass after correction. Muse's proposed success after killing an
installer was not adopted: later installation steps may remain incomplete even if
the binary version changes. Grok's hypothetical checked:false response from POST
cannot occur in the implemented server; intentional empty-cache recovery is preserved.

The initial candidate was superseded after the completed Grok review. Its passing
CI/signing receipts were not reused for the final source. This release also includes
accumulated main-branch features and reliability corrections in `desktop/CHANGELOG.md`,
including standalone CLI management and scheduled task families in the sidebar.
