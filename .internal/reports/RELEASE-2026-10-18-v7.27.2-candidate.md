## Integration and fixes

The hotpath stability and release branch tips were already ancestors of main. The candidate incorporates the previously unpushed supervision, Streamlit, analysis app, security, lifecycle, streaming, and runtime/SDK updates. The user-provided local reference index update is retained and committed.

- A remounted project launcher records Streamlit readiness and its preview URL without navigating away from the current view.
- Optional development-server file reads await the response body inside the error handler, so interrupted bodies cannot leave Streamlit discovery pending or rejected.
- Returning to a visible window reports a stale connection as a heartbeat timeout before reconnecting, including connections that previously survived the healthy window.
