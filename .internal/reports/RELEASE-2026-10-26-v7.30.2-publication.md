Correct A-B-A pending snippet display ownership, removal loading state, oversized payload cache flushing, and reentrant directory disposal. Before-fix regressions and passing behavior tests are retained.

The host window is affected only while the temporary view exists. Native ASAR smoke verifies all six sampled clips reach 72 frames and reduced motion remains honored.

All four runtime archives/signatures, SDK producer tag and authenticated tarball integrity were freshly checked; latest stable runtime was checked again immediately before tag creation.
