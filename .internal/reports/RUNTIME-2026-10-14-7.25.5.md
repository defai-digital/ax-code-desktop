# Runtime pin: 7.25.3 → 7.25.5

Date: 2026-10-14

## Outcome

The pinned signed runtime moves from 7.25.3 to 7.25.5, the release AX Code pairs with the
SDK 2.6.16 the desktop now consumes (`75222d1b`). All four pinned platform artifacts were
downloaded from the public release and verified before the pin moved.

## Evidence

- Release `v7.25.5`, published `2026-10-14T10:42:01Z`, carries the four pinned targets and
  their `.minisig` signatures plus the public key `ax-minisign.pub`.
- The published public key is byte-identical to the committed `resources/keys/ax-minisign.pub`.
- Each artifact's size and SHA-256 were computed from the downloaded bytes, and each
  Minisign signature verified with the committed key; the signed trusted comment's embedded
  digest matches the computed one for every artifact.
- darwin-arm64 was staged and booted on this machine: `ax-code --version` reports 7.25.5 and
  `serve --hostname 127.0.0.1 --port 51277` answered `/global/health` with
  `{"healthy":true,"version":"7.25.5", ...}` (all 13 services `running`, no failures). The
  process was killed afterwards and the temporary profile removed.
- Note the release now ships a smaller archive (darwin-arm64 79,120,963 bytes vs
  161,148,106 at 7.25.3) because runtime archives no longer bundle AX Engine — it is
  resolved from a configured, PATH or managed installation instead.

Receipt: [.internal/reviews/release-7.25.5/runtime-verification.json](../reviews/release-7.25.5/runtime-verification.json).
