# Desktop v7.25.0 publication evidence

Date: 2026-10-13 UTC
Status: Published and independently verified.

The explicit user request authorizes this publication under ADR-012. Release tag
[v7.25.0](https://github.com/defai-digital/ax-code-desktop/releases/tag/v7.25.0)
resolves to `fefa88ffec3d74453d690370eb2c58bd144e8698`. The candidate consumes
published SDK 2.6.14 and signed runtime 7.25.3. The Rust event bridge remains an
unpublished experiment and is not enabled.

## Source and verification

- [Desktop CI](https://github.com/defai-digital/ax-code-desktop/actions/runs/38374156082): all six jobs passed, including four native targets and packaged macOS smoke.
- [CodeQL](https://github.com/defai-digital/ax-code-desktop/actions/runs/38374156101) and [Code Quality](https://github.com/defai-digital/ax-code-desktop/actions/runs/38374155633) passed on the exact candidate.
- [Required-signing shadow](https://github.com/defai-digital/ax-code-desktop/actions/runs/38374173750): all jobs passed. Attempt 2 reran macOS after Apple accepted attempt 1's notarization but its ticket download lost the network connection (stapler error 68).
- Local workspace validation passed 3,160 tests with 7 existing skips, frozen installation, typecheck, lint, build, boundaries, locale and workflow checks. The scoped animation controller/player checks passed 17 tests. Details and bounded Grok/Muse review receipts are in the implementation plan and `.internal/reviews/release-7.25.0/`.

Native CI now bundles animation assets before smoke tests. Smoke playback uses
separate processes for normal and reduced-motion preferences. Hosted Linux arm64
measured a 3,306 ms cold renderer load and 6,319 ms first playback; the decode
fixture allows 15 seconds while production retains its six-second UX deadline.
All six clips decoded 72 frames; reduced motion decoded zero. Windows CORS
profiles are removed by the parent after Electron exits.

Verified review fixes preserve flat events with nested payloads, retain events
without an ID for replay/resync, snapshot qualified upload bytes before mutation,
and determine immutable R2 collisions from authoritative storage.

## Native qualification

fresh install, baseline install, upgrade, rollback and final install, preserving
profile/configuration hashes. Candidate installed ASAR CLI/UI smoke passed after
fresh install, upgrade and final install. Baseline 7.24.5 was installed but not
executed. These receipts cover installer continuity with synthetic configuration;
they do not claim historical GUI database migration, live provider authentication
or Windows ACL continuity. POSIX regular-file status, mode, owner and group were

updater feeds match the qualified bytes and their referenced artifact SHA-512;
all seven referenced updater artifacts are anonymously available at the expected

already active Desktop gateway. Every object passed authenticated R2 and anonymous

## Integration and preservation

Fetching/pruning and worktree inspection found only Desktop main and origin/main,
with one registered worktree. No additional branch/worktree required integration
or deletion. The previously local SDK integration commit is now an ancestor of
the pushed release source. Historical signed releases, the protected baseline
fixture and sibling workspaces are preserved. The isolated Linux reproduction
container was removed and its task-specific image deleted. Release artifacts,
receipts and operator verification scripts are retained with the release evidence;
only task-owned temporary copies are eligible for cleanup.
