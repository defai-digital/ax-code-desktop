# AX Code Desktop 7.26.0 candidate verification

The candidate starts from `e241d0b4b97e67ddc774faa628f34f49b6a60b1d` and preserves the primary checkout. It consumes signed AX Code runtime 7.26.0 and exact published SDK 2.6.22.

## Reproduced fixes

- Scheduled CLI checks and settings re-entry previously read the last cached GET forever. Explicit checks now POST with `refresh: false`, delegating cache expiry to the server. Progress polling still uses the read-only GET.
- After the polling reachability timeout, a successful fallback returning a running job left settings disabled indefinitely. The view now resumes following that job.
- A pre-upgrade JSON check with a known installer method but an error still started the installer. Upgrade admission now requires a confirmed available update and refuses an indeterminate check with HTTP 503.

The regression tests failed against the original behavior before the fixes. They cover six-hour scheduled discovery, settings re-entry, read-only polling, connection recovery, and installer refusal.

## Independent review

Muse completed a bounded source-snapshot review with filesystem writes, shell and web tools disabled. Its recovery and failed-precheck findings were reproduced and fixed. Its proposed success-after-installer-timeout change was not adopted: killing an installer may interrupt steps after the executable replacement, so a matching version alone does not prove installation completion. The source comment now makes that existing timeout policy explicit.

Grok source-snapshot review is in progress. Its completed receipt and disposition are required before publication; an empty or timed-out run does not count as review evidence.

## Local validation

`pnpm install --frozen-lockfile`, full tests (4,170 passed, 8 existing conditional skips), typecheck, lint, Desktop build, boundary/release contracts, 14-locale parity, actionlint and `git diff --check` all passed. Focused regressions were also run before and after the fixes.

## Publication gates

The implementation commit must pass full local validation, exact-source Desktop CI and CodeQL, and required signed shadow qualification for macOS arm64, Windows x64, Linux x64 and Linux arm64. Fresh installation, baseline installation, upgrade, rollback, final installation and synthetic profile/configuration continuity receipts must bind to the same source and signed installer inventory. Publication requires verified public GitHub assets/updater feeds and authenticated plus anonymous download-channel readback. No publication claim is made in this candidate report.
