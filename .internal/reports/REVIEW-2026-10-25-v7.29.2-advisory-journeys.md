## Follow-up from cross-platform reruns

The first rerun exposed a Linux draft-selection failure after the original checkpoints: development startup argv included the Electron app-entry directory, and the open-path collector treated it as a user-requested project. Its deferred project-open event could replace the fixture selection. An actual Electron probe confirms defaultApp=true and the executable/entry argv shape. The new collector drops those two launch arguments only when they match an Electron development launch; plain file-open events and packaged project arguments remain intact. The new regression fails before the fix; 13 focused open-path tests pass after it. Packaged v7.29.2 starts do not use defaultApp.

Reusing canonical Windows identity also exposed a case-sensitive Archive journey assertion. That assertion now compares the shared path identities while retaining the actual captured request records; POSIX paths remain case-sensitive. No project ownership assertion is removed.

Superseded CI attempts and intermediate native failures remain excluded from final passing claims. The final cross-platform source rerun and repeated local gates will be recorded below when complete.

The reruns also exposed control-observation races: Settings had been clicked but its Chat navigation was not mounted yet, and a page switch looked up a dynamic accessible name again after observing it. The harness now waits for the Settings view and invokes the fresh page control reference from the observed UI state. Assertions, existing per-wait deadlines, screenshot deadlines and production rate limits are unchanged.

A local verification caught a stale-reference mistake introduced during this investigation: aggregating multiple UI inventory pages invalidated earlier-page refs. The final switcher lookup stops on the matching inventory page and invokes that ref immediately, preserving the product's document-local ref expiry contract. The failed attempt is retained and excluded. The corrected native browser journey passes all 50 stress switches and the subsequent grid checks. Native Tasks and Supervision also pass. Repeated local six-gate validation reports 8,189 passed tests and 10 skipped; hosted final-source verification remains pending.

The Windows payload regression caught an investigation mistake: canonicalizing a comparison key had also lowercased serialized path payloads and archive event envelopes. The fixture now uses shared identity only for comparisons and preserves its existing wire spelling. A spawned-runtime regression checks /path, recorded archive writes and the actual SSE session.updated envelope; it fails before the correction and passes afterward. The 23 scenario tests and nine UI-client tests pass. W7 also waits for the specific waiting-page announcement before acting on the pre-existing Needs you button, so a changing attention count is not mistaken for frontend readiness. No retries or relaxed ref checks are used.
