## Confirmed defects and fixes

- Concurrent settings failures consumed a process-wide retry counter; unrelated successful writes reset it. Retry attempts now travel with the queued batch. Coalescing preserves the least-used budget, and new edits get a fresh budget without shortening an active backoff. Focused tests cover concurrent failures, intervening success, bounded exhaustion and new edits during the final backoff.
- A failed hidden-window write requeued keys that a newer flush already saved. Its failure handler now retains only keys still owned by that write sequence. A deferred-write regression proves the old value is not resent. Retained failed background writes also enter the bounded retry queue without requiring another user edit.
- An older successful save arriving after a newer failed save left the read cache unchanged. Every successful write now invalidates the cache even when its response is too old to apply to the UI; hidden-window writes also invalidate on completion, so a GET during the write cannot retain an obsolete snapshot. A regression primes the cache, overlaps two writes, fails the newer one and proves the next sync makes a fresh GET.

CodeQL alerts 181-185 in the existing Archive all journey exposed an unconstrained fixture-file network destination and raw network data written to the receipt. The journey now reconstructs only a validated IPv4 loopback origin, rejects redirects, verifies created fixture IDs against deterministic local IDs, and records checked numeric write counts instead of unvalidated server writes. Fifteen behavior tests cover accepted ports and rejected remote URLs, credentials, paths, queries, fragments and invalid ports. Exact-source CodeQL readback must confirm automatic resolution before publication; no alert is dismissed.

The existing project-wide Archive all behavior is included in this release. Its membership and confirmation semantics have focused tests and a committed WebMCP journey. No runtime ownership boundary was changed.
