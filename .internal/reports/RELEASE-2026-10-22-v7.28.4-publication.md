- Add a per-turn transcript timeline rail and move the sessions sidebar control to the left of the header.
- Preserve the selected composer model across sends, failed optimistic messages and directory activation. Restore a loaded session's agent independently of runtime-routed model coordinates, retain submitted effort and keep per-agent memories distinct from the session pick.
- Treat initial and delayed agent/provider discovery as hydration, so a saved agent pin cannot overwrite the session pick. Ready-mount, delayed hydration, legacy missing-agent history and real manual switches have rendered regressions.

- Integrate coalesced supervision previews, bounded browser polling and layout work, weak transcript caching, deleted-session attachment cleanup and retired-directory routing cleanup. These are mechanism-level changes; no measured performance improvement is claimed.
