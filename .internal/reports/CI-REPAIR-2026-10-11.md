# Desktop CI repair after main consolidation

The first independent main-branch run (`38184032376`, source `c1fdef57919093f7941b7f11552400953f80578f`)
exposed four runner-specific failures. macOS and Windows x64 native compatibility passed.

- Ubuntu x64 and ARM64 found Electron's SUID sandbox helper without root ownership and mode 4755.
  CI now configures the installed helper before launching Electron. The smoke runs retain sandboxing.
- The full UI store-boundary integration test exceeded Vitest's five-second default on a shared runner.
  Only that repository-wide parsing test has a bounded 30-second timeout; policy assertions are unchanged.
- Windows ARM's Visual Studio 2026 was unsupported by the old Electron node-gyp fork.
  The explicit native rebuild now uses exact `@electron/rebuild` 4.2.1 and upstream node-gyp 12.2.0.
- Packaging tried to download a private sibling repository's release without credentials.
  Canonical runtime staging now uses AX Code's public versioned release mirror, as its installers do.
  Explicit alternate repositories still use their own GitHub release URLs.

The public macOS ARM64 runtime and signature were downloaded independently. Their SHA-256 values
are exactly the existing `config/ax-code-runtime.json` pins:

```text

5b5a83fdeb52de5cc43d25302cd2706a0bf92a326988b9f6f411c5291e9ab86f  ax-code-darwin-arm64.zip.minisig
```

Minisign verified both the signature and trusted comment with the checked-in public key.
Runtime version, size/hash checks, signature verification, required-runtime enforcement, Desktop
identity, and the shadow-only release policy are unchanged. No new secret or repository permission
is required.

Local root tests (69) and Electron tests (452) passed. Native rebuilding, menu/PTY smoke, and all
three native WebMCP probes passed on macOS ARM64 with Electron 45.0.0-beta.1 / Chromium 156.0.8078.12.
Frozen dependency installation, typechecking, lint, repository/release boundaries, workflow syntax,
and the three-task Desktop build passed locally.
Cross-platform runner results must be verified on the repair commit before claiming CI completion.

The follow-up local required-runtime package reached the ASAR integrity gate, exposing a directory
classification bug: `@msgpack/msgpack/dist.cjs` was treated as a JavaScript file. The verifier now
distinguishes directory entries and still verifies every code file below them. A regression verifies
that layout and then corrupts a nested file to prove rejection remains enforced. All nine verifier
tests and the actual packaged ASAR/fuse checks passed, followed by bundled-runtime and packaged-app
smoke checks. The Linux helper setup also initializes Electron before resolving its package path,
so lazy download progress cannot contaminate the shell path variable.
