# Desktop v7.25.1 publication evidence

Date: 2026-10-15 UTC
Status: Published and independently verified.

The explicit user request authorizes publication under ADR-012.
[Release v7.25.1](https://github.com/defai-digital/ax-code-desktop/releases/tag/v7.25.1)
and its lightweight tag resolve to `7d9fdf808f3b6a4d4ea9e57a19ee62ab7f32fbf7`.
The release consumes published AX Code SDK 2.6.17 and pinned signed runtime 7.25.7.

## Fixes and source verification

Muse CLI and Grok CLI completed bounded read-only reviews. Confirmed issues were
reproduced with regressions and fixed: worktree matches hiding registered nested
projects, ancestor fallback hiding an exact worktree owner, and stale external
project discovery success/failure overwriting a reopened dialog. Review receipts
are in `.internal/reviews/release-7.25.1/` and the implementation record is
`BUGFIX-2026-10-14-v7.25.1.md`.

- [Exact-source Desktop CI](https://github.com/defai-digital/ax-code-desktop/actions/runs/38672703386): all six jobs passed.
- [Exact-source CodeQL](https://github.com/defai-digital/ax-code-desktop/actions/runs/38672705635): passed.
- [Required signed shadow](https://github.com/defai-digital/ax-code-desktop/actions/runs/38672707805): all jobs passed after rerunning macOS on the same immutable source.
- Local frozen install, typecheck, lint, build, boundaries, release contract, locale checks and actionlint passed. Full tests: 3,771 passed, 7 existing skips. The focused regression suite passed 10 tests; original source failed three ownership cases and both import lifecycle tests.

Attempt 1 accepted app and DMG notarization and passed DMG stapling/Gatekeeper,
but failed mounted-app ticket validation during native qualification. The original
failure was preserved. Attempt 2 passed that exact gate and every native transition;
no signing, installation, ticket, or continuity gate was bypassed. A successful
notarization submission alone was not treated as qualification.

## Public distribution

All 74 GitHub asset server digests match local bytes, including six final signed
public verification/upload receipt files. The public tag and latest release point
to v7.25.1. Four anonymous updater feeds match qualified bytes; all referenced
artifacts match their SHA-512 and are anonymously available at their expected sizes.

The canonical qualified REST uploader published 48 objects to the existing Desktop
R2 bucket/gateway. Every object passed authenticated storage and anonymous byte
readback before its operation completed; bootstrap aliases and latest advanced last.
All files were below the 300 MiB REST guard, so multipart and a temporary Worker
were unnecessary. An expired OAuth session initially returned HTTP 401; refreshing
the existing Wrangler login restored access without changing permissions.

A separate curl/Minisign verification independently downloaded and compared 18
versioned metadata, signature and root-alias objects, verified their pinned-key
signatures, and checked readiness against the exact source and manifest. Both public
GitHub and download-gateway latest pointers are v7.25.1. The prior CLI installer
remains available.

## Preservation and integration state

Fixes and publication evidence are pushed on `fix/desktop-7.25.1`; the release tag
pins the qualified source before this report-only commit. No automatic merge was
performed. The main checkout's uncommitted CI optimization work and subsequent
commits were preserved. The qualified candidate remains in its isolated worktree;
local signed assets, receipts, verification scripts and failure evidence are retained
under `.internal/releases/v7.25.1-evidence/` there. Sibling repositories and historical
signed releases were not modified.
