## Integration and fixes

The release includes all committed development work through r29, plus the previously unpushed session-retention fixes. No Desktop/runtime ownership boundary changed.

- Cascading session deletion preserves kept descendants, including archived children and active descendants reached through archived intermediates. Preview and execution use the same action-aware rules. Archive mode still archives an eligible parent whose child is already archived. Incomplete active/archived inventories block cleanup. Already-absent sessions count as completed idempotent cleanup.
- WebMCP diagnostics mask repeated credential values and scalar/encoded echoes. Original tool outcomes are classified before display redaction; keyed occurrence receipts preserve checker integrity. Tool identity receipts are protected separately from display payloads, including when display names themselves redact.
- Sensitive-echo collection is bounded to 256 distinct values and 16384 characters. Overflow marks the projection incomplete and hides it as a whole. A 765041-byte diagnostic probe improved from approximately 442 ms to 50 ms on this host; this is a bounded probe, not a general benchmark guarantee.
- Tool identity survives temporary registration gaps. Cancelled closure retains page bindings and does not reveal hidden-page login popups. Failure summaries, off-list input replay, waiting-page status, grid browser pages and complete never-called evidence are included.
- Vitest is pinned to 4.1.12, fixing GitHub alerts GHSA-qxg6-89mg-rqv8 and GHSA-xp26-3454-mjgp. Parsed-lockfile comparison confirms all non-Vitest package/snapshot records and other importers are unchanged. A frozen installation passed.
