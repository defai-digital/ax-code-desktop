# AX Code Desktop v7.30.6 verified publication

AX Code Desktop v7.30.6 is published on [GitHub](https://github.com/defai-digital/ax-code-desktop/releases/tag/v7.30.6) and the existing [download channel](https://download.automatosx.com/ax-code-desktop/).

## Source and fix

The immutable qualified source/tag is `b0ee5937c37ed826afb69ef41b0a6a826ced4eaa`. The Desktop-owned terminal paste sanitizer previously removed only markers present in the original text. An embedded marker could split another marker's bytes; deleting the inner marker reconstructed a valid outer marker, allowing nested pasted text to terminate the bracketed-paste wrapper early.

The sanitizer now reduces a character stack during one pass. Removing a marker cannot leave a reconstructed marker in output, and deep nesting does not cause repeated full-input scans. Four failing-before regressions cover opening/closing markers in both 7-bit and 8-bit forms. Additional coverage includes mixed markers nested 10,000 levels deep, Unicode text, unrelated escapes, incomplete markers and unchanged behavior when bracketed paste is disabled. The focused paste/viewport suites passed twelve tests.

AkiTTY v0.12.0 remains pinned to `6c6052f74bd83032933f153b9940a331f794543f` with 48 source hashes verified. Its upstream Web package version remains 0.5.0. The runtime remains signed AX Code 7.30.1 and SDK 2.6.53; the dependency lock did not change. No agent permissions, native clipboard APIs or upstream terminal implementation were changed.
