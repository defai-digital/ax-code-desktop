## Changes and integration

Existing main-branch work was retained and merged, including asynchronous runtime hashing/version probing, overlapping login-shell capture, idle-frame reduction, and removal of unused experiments and dependencies. Three additional scroll-shadow defects were reproduced and fixed: lost subscriptions after replacing the host element, missing visibility transitions across disable/re-enable, and stale attributes after changing orientation. Each regression failed before its fix and passed afterward.

Muse CLI and Grok CLI completed bounded independent reviews. Unsupported suggestions were checked and rejected; timed-out attempts were retained as incomplete evidence. See [review dispositions](../reviews/release-7.27.0/dispositions.md) and the [candidate record](RELEASE-2026-10-17-v7.27.0-candidate.md).

The release consumes signed AX Code runtime 7.27.0 and exact public JSR SDK 2.6.29. Four producer archives and their signatures, the producer commit, and the SDK archive integrity were independently verified. See the [producer integration record](INTEGRATION-2026-10-17-ax-code-7.27.0-sdk-2.6.29.md). A native Electron smoke rendered the runtime-owned Wiki viewer with the canonical CSP and no Node integration. Native CI covered WebMCP on all four platforms. No sibling checkout or separately installed CLI was modified.
