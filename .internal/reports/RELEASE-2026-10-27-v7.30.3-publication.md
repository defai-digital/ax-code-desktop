AX Code Desktop v7.30.3 is published on [GitHub](https://github.com/defai-digital/ax-code-desktop/releases/tag/v7.30.3) and the existing [download channel](https://download.automatosx.com/ax-code-desktop/).

## Immutable source and fixes

The qualified source and immutable tag are `79146001d873e82d5a85486f21e0be550b794914`. The release preserves all ten previously unpushed commits, adds a cross-project Wiki retry-state regression/fix, and removes the release-evidence test's stale version literal. The test now reads the release manifest.

Included fixes restore AX Trust setup/management metadata, retain registered projects' Git summaries beyond the bounded working set while removing deleted projects/worktrees, align Git comparison history with statistics, accept discovered JPEG icons, persist projects before icon discovery, update context-tab editability, normalize Windows drive letters, preserve partial update-feed results, classify Wiki viewer failures, and await every viewer export cleanup at shutdown. Wiki reloads retry transient failures within a fixed bound and discard stale poll outcomes after a project or refresh generation changes.

The bundled runtime remains signed AX Code 7.30.1 with exact SDK 2.6.53. No runtime/SDK dependency was changed in this release.
