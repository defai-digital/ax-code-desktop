Top finding: external admission accepts most IPv6 link-local literals.

1. **IPv6 link-local range is incomplete.** `isBlockedExternalHost` checks `host.startsWith("fe80")`, but link-local is `fe80::/10`, covering `fe80` through `febf`.  
   **Trigger:** `normalizeProxyTargetUrl("http://[febf::1]/", { allowExternal: true })` returns `{ ok: true }`; `fe90::1` and `fea0::1` behave likewise.  
   **Regression test:** assert `fe80::1`, `fe90::1`, `fea0::1`, and `febf::1` are refused, while a global address such as `2606:4700:4700::1111` remains allowed.

2. **Trailing-dot loopback names are admitted by neither path.** `isBlockedExternalHost` strips the root dot, but `isLoopbackHost` and loopback canonicalization require exactly `localhost`.  
   **Trigger:** `normalizeProxyTargetUrl("http://localhost.:5173/", { allowExternal: false })` is rejected. A local preview redirect to `http://localhost.:5173/next` also fails: the loopback check misses it, then the external check blocks it as `localhost`, so `rewriteProxyRedirectLocation` returns `null`.  
   **Regression test:** assert `localhost.:5173` normalizes to the same local origin as `localhost:5173`, and that such a same-port redirect keeps the existing proxy target ID instead of returning `null`.
