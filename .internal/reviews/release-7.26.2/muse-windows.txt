1. **`.cmd` launch breaks on `%…%` install paths** — [axcode-runtime-supervisor.js](/tmp/ax-desktop-7.26.2-review/desktop/packages/electron/src/axcode-runtime-supervisor.js) `resolveSpawnInvocation`. Trigger: install to a literal folder such as `D:\%OS%\AX Code`, allowed by the NSIS directory picker, or set `settings.axCodeBinary` under one. Cmd expands `%OS%` even inside quotes, so it tries `D:\Windows_NT\…\ax-code.cmd`. Smallest fix: pass the binary path through a dedicated environment variable and invoke `"%AX_CODE_RUNTIME_BINARY%" …`; do not interpolate the raw path into the `/c` string.

2. **Windows “graceful” stop is an immediate force-kill, and `taskkill` failure is treated as success** — same file, `killProcessTree`. Trigger: any quit/restart on Windows: `gracefulStopRuntime`’s `SIGTERM` becomes `taskkill /t /f`, skipping the grace period. If `taskkill` exits non-zero, `spawnSync` leaves `error` undefined, so the code returns without the `child.kill` fallback and the runtime can keep the fixed port. Fix: use `/f` only for `SIGKILL`, and require `result?.status === 0` before returning.

3. **Windows `PATH` lookup diverges from `PATHEXT`** — same file, `searchPathFor`/`defaultIsExecutable`. Trigger: an earlier `PATH` directory contains an extensionless `ax-code` shim, or only `ax-code.bat` exists. Windows `X_OK` is effectively an existence check, so the bare shim is accepted and then spawned directly, failing instead of falling through; `.bat` is never tried despite being handled by `resolveSpawnInvocation`. Fix: on `win32`, try only `.exe`, `.cmd`, `.bat`, `.com` from `PATHEXT`; drop the bare name.

4. **Wiki temp deletion races Chromium file handles on Windows** — [wiki-viewer.js](/tmp/ax-desktop-7.26.2-review/desktop/packages/electron/src/wiki-viewer.js) `closeAll` and the `open` error path. Trigger: quit while a snapshot is loading/open. Windows are destroyed and the temp directory is removed immediately, in parallel with the `closed` handler removing it again; Windows can return `EPERM`/`EBUSY` for the still-open snapshot, making shutdown reject. Fix: await each window’s `closed` event, delete once, and use `fs.rm(..., { maxRetries: 10, retryDelay: 100 })`.

5. **Installer cleanup can mask success or the real error** — [install.ps1](/tmp/ax-desktop-7.26.2-review/.internal/deploy/install.ps1). Trigger: Defender or another process briefly holds the downloaded installer/verifier when the `finally` block runs. `Remove-Item -Recurse -Force` under `$ErrorActionPreference='Stop'` throws, so a successful install exits as failure, or the original download/verification error is replaced. Fix: make cleanup best-effort with `-ErrorAction SilentlyContinue`.
