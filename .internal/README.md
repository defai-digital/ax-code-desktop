# AX Code Desktop internal records

This directory contains private product-development records for AX Code Desktop.

- `prd/`: live, deferred, completed, and archived product requirements
- `adr/`: architecture decisions
- `spec/`: technical specifications

Public user and operator documentation belongs in `docs/` only after the corresponding behavior ships.

Phase 1 history extraction is complete, and Phase 2 independent-workspace implementation is in progress. The source
of truth for the accepted product and Desktop extraction program is
`prd/PRD-2026-09-02-ax-coder-product-and-desktop-extraction.md`; extraction evidence is under
`reports/extraction/`.
